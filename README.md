# MhWangZi的简历工作台

通用岗位简历编辑器。修改文字、预览排版，按投递方向保存版本，再导出PDF或可离线编辑的网页。

## 使用

在线使用：https://mhwangzi.github.io/resume-workbench/

1. 在基本信息和求职意向中填写自己的资料。初始内容全部是通用填写提示。
2. 编辑教育、工作、项目与专业能力。模块可以改名、隐藏或调整顺序。
3. 专业实践和案例分析各自提供可编辑的通用、产品／运营、技术／工程预设。简历一次只显示当前选中的一个案例。
4. 使用间距、字号、主题色和模板设置调整排版。直接PDF导出支持一页A4；多页请使用浏览器打印。
5. 重要版本使用“版本与备份”保存快照或下载JSON备份。

## 保存与隐私

- 编辑内容只写入当前浏览器的localStorage，没有账户、后端、遥测或简历上传接口。
- 同一浏览器、同一站点地址会恢复上次的内容；换浏览器、换地址、清理网站数据不会自动同步。
- “备份全部材料”和“保存网页”包含当前资料、全部预设和已存版本。请仅与需要的人分享这些个人导出文件，不要提交到公开仓库。
- 公共仓库只提供通用模板，初始照片、联系方式和作品链接均为空，不包含个人简历或历史版本。
- 链接仅在你主动点击时打开。页面的代码、字体资源由静态站点提供。

## 本地运行

需要Python 3，在项目目录运行：

```sh
python -m http.server 8788 --bind 127.0.0.1
```

打开http://127.0.0.1:8788/。初次直接打开index.html会限制字体及网页打包功能，建议通过本地服务运行。下载的独立工作台HTML可以直接打开并离线编辑。

## 项目结构

- `template.json`：供参考和导入的基础模板。
- `src/core.js`：状态、校验、自动保存、备份和版本管理；INITIAL是应用初始模板。
- `src/editor.js`：模块、预设、富文本与预览。
- `src/pdf-export.js`：带嵌入字体和链接的PDF导出。
- `src/portable.js`：离线网页打包与导出状态。
- `assets/fonts`：Noto Sans SC常规与粗体字体及SIL OFL许可。
- `assets/vendor`：pdf-lib与fontkit及各自许可。

无构建步骤。GitHub Actions直接部署经过检查的静态文件，不会部署本地备份或运行日志。

## 限制

浏览器打印的排版由浏览器决定。直接PDF导出以一页简历为目标，支持常规文本、粗体、斜体、下划线、列表、照片和链接；特殊排版和字体未覆盖的字符可改用浏览器打印。字体完整嵌入会使PDF比纯文本文件大，避免在其他电脑缺字或替换字体。
